## Summary

Stockfish_v2 is a resumable PGN-to-Parquet pipeline that joins human-game metadata with
Stockfish evaluation features, to support sequence-modeling of win, draw, and loss
probabilities. Built solo, 2026.

## Context and constraints

Source PGN datasets are large enough that a single run isn't practical to redo from scratch
after an interruption, so the pipeline had to be resumable and produce a consistent Parquet
output across runs.

## Approach

Built the pipeline around Stockfish 11 and 18 evaluation features joined against human-game
metadata, writing resumable checkpoints so a run can pick up where it left off rather than
reprocessing from the start.

## Evaluation

Not yet benchmarked against a trained sequence model — this project currently covers the data
pipeline that would feed one.

## Result

A working, resumable data pipeline producing joined PGN and Stockfish-evaluation features in
Parquet, ready for downstream sequence-modeling work.

## What changed

The modeling stage (training a sequence model on the pipeline's output) is the natural next
step and hasn't been built yet.
